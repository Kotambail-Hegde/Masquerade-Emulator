WHY MASQUERADE

More than
just playing games.

01

Deep debugging

Granular execution control with frame, line, and tick-level debugging for emulator development.

02

Hardware features

Game Boy Camera, Game Boy Printer, serial peripherals, cheats, save states, and more.

03

Modern architecture

Built on Dear ImGui, SDL3, OpenGL3, and native file dialogs.

04

Cross-platform

Desktop builds and a WebAssembly version make the emulator accessible without installing anything.

05

Mappers & MBCs

49 NES mappers and 15 Game Boy Memory Bank Controllers, covering common carts through obscure boot-legs.

06

Source-available

Source code, tests, and development history are public on GitHub for reference, study, and non-commercial use.
